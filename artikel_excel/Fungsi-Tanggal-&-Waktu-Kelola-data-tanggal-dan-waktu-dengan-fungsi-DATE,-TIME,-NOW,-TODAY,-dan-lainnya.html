Fungsi Tanggal & Waktu Excel: Panduan Lengkap

25 Juni 2023 18.5K Dilihat 28 menit membaca Excel, Tanggal, Waktu, DATE, NOW, TODAY

Fungsi tanggal dan waktu di Excel adalah alat essential untuk mengelola data temporal, menghitung durasi, membuat jadwal, dan melakukan analisis berbasis waktu. Dengan menguasai fungsi-fungsi ini, Anda dapat mengotomatisasi banyak tugas yang berkaitan dengan waktu.

Fakta Penting: Excel menyimpan tanggal sebagai angka serial, dimana 1 = 1 Januari 1900. Ini memungkinkan perhitungan matematika pada tanggal.

1. Fungsi Tanggal & Waktu Dasar

Fungsi Pembuat Tanggal dan Waktu

Fungsi Deskripsi Syntax Contoh
DATE Membuat tanggal dari tahun, bulan, hari =DATE(tahun, bulan, hari) =DATE(2023, 6, 25) → 25/06/2023
TIME Membuat waktu dari jam, menit, detik =TIME(jam, menit, detik) =TIME(14, 30, 0) → 14:30
NOW Tanggal dan waktu saat ini =NOW() =NOW() → 25/06/2023 14:30
TODAY Tanggal hari ini =TODAY() =TODAY() → 25/06/2023

2. Fungsi Ekstraksi Komponen Tanggal & Waktu

YEAR, MONTH, DAY Pemula

Mengambil tahun, bulan, atau hari dari tanggal.

=YEAR(tanggal)
=MONTH(tanggal)
=DAY(tanggal)

Contoh: =YEAR("25/06/2023") → 2023

HOUR, MINUTE, SECOND Pemula

Mengambil jam, menit, atau detik dari waktu.

=HOUR(waktu)
=MINUTE(waktu)
=SECOND(waktu)

Contoh: =HOUR("14:30:25") → 14

WEEKDAY Menengah

Menentukan hari dalam seminggu (1=Minggu, 7=Sabtu).

=WEEKDAY(tanggal, [type])

Contoh: =WEEKDAY("25/06/2023", 2) → 1 (Senin)

3. Fungsi Perhitungan Tanggal

Fungsi untuk Kalkulasi Tanggal

Fungsi Deskripsi Syntax Contoh
DATEDIF Menghitung selisih antara dua tanggal =DATEDIF(start_date, end_date, unit) =DATEDIF(A1,B1,"D") → selisih hari
EDATE Tanggal setelah sejumlah bulan =EDATE(start_date, months) =EDATE("25/06/2023", 3) → 25/09/2023
EOMONTH Tanggal terakhir bulan setelah sejumlah bulan =EOMONTH(start_date, months) =EOMONTH("25/06/2023", 0) → 30/06/2023
WORKDAY Tanggal kerja setelah sejumlah hari =WORKDAY(start_date, days, [holidays]) =WORKDAY("25/06/2023", 5) → 02/07/2023

4. Contoh Praktis Penggunaan

Contoh 1: Menghitung Usia

Data: Tanggal lahir "15/03/1990" di sel A1

=DATEDIF(A1, TODAY(), "Y") & " tahun, " &
DATEDIF(A1, TODAY(), "YM") & " bulan, " &
DATEDIF(A1, TODAY(), "MD") & " hari"
Hasil: "33 tahun, 3 bulan, 10 hari"

Contoh 2: Menghitung Jatuh Tempo

Data: Tanggal invoice "20/06/2023" di sel A1, Term 30 hari

=WORKDAY(A1, 30) // Jatuh tempo 30 hari kerja
=A1 + 30 // Jatuh tempo 30 hari kalender

Contoh 3: Analisis Data Penjualan Bulanan

Data: Tanggal transaksi di kolom A, Jumlah di kolom B

// Total penjualan bulan ini
=SUMIFS(B:B, A:A, ">="&EOMONTH(TODAY(),-1)+1, A:A, "<="&EOMONTH(TODAY(),0))

// Rata-rata harian bulan ini
=AVERAGEIFS(B:B, A:A, ">="&EOMONTH(TODAY(),-1)+1, A:A, "<="&EOMONTH(TODAY(),0))
Pro Tip: Gunakan EOMONTH untuk dengan mudah mendapatkan tanggal pertama atau terakhir bulan. EOMONTH(TODAY(),-1)+1 = tanggal pertama bulan ini.

5. Format Tanggal dan Waktu

TEXT Function

Mengubah tanggal menjadi teks dengan format tertentu.

=TEXT(tanggal, "format")

Contoh: =TEXT(TODAY(), "DDDD, D MMMM YYYY") → "Minggu, 25 Juni 2023"

Format Cells

Format built-in Excel untuk tampilan tanggal.

dd/mm/yyyy → 25/06/2023
dddd → Sunday
mmmm yyyy → June 2023

DATEVALUE & TIMEVALUE

Mengubah teks menjadi nilai tanggal/waktu.

=DATEVALUE("25/06/2023")
=TIMEVALUE("14:30:00")

6. Kombinasi Fungsi Tanggal yang Powerful

Formula Kombinasi untuk Kasus Kompleks

Menghitung Umur Project

Data: Start Date: "01/01/2023", End Date: "31/12/2023"
// Total hari project
=DATEDIF(A1, A2, "D") // 364 hari

// Hari kerja project
=NETWORKDAYS(A1, A2) // 260 hari (approx)

Membuat Timeline Otomatis

Data: Start Date: "01/07/2023", Duration: 90 hari
=A1 // Start: 01/07/2023
=WORKDAY(A1, 30) // Milestone 1: 11/08/2023
=WORKDAY(A1, 60) // Milestone 2: 22/09/2023
=WORKDAY(A1, 90) // Deadline: 03/11/2023

7. Common Mistakes dan Solusi

Kesalahan Umum dalam Fungsi Tanggal & Waktu:

  • Format regional: DD/MM/YYYY vs MM/DD/YYYY
  • DATEDIF hidden: Fungsi bekerja tapi tidak muncul di autocomplete
  • NOW() volatile: Nilai berubah setiap kalkulasi ulang
  • Date as text: Tanggal disimpan sebagai teks bukan nilai tanggal
  • Leap year: Perhitungan melompati tahun kabisat

8. Tips dan Best Practices

Validasi Tanggal

Gunakan Data Validation untuk memastikan input tanggal valid.

Static Timestamps

Gunakan Ctrl+; untuk timestamp statis, NOW() untuk dinamis.

Holiday Calendar

Buat daftar hari libur untuk perhitungan WORKDAY yang akurat.

Dengan menguasai fungsi tanggal dan waktu Excel, Anda dapat membuat sistem yang responsive terhadap waktu, mengotomatisasi laporan periodik, dan melakukan analisis tren temporal dengan presisi. Practice dengan data nyata untuk semakin mahir!
