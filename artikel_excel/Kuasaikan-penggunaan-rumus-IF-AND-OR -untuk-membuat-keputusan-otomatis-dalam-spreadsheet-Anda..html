Rumus IF dan Logika Excel: Panduan Lengkap AND, OR untuk Keputusan Otomatis

📅 25 Maret 2023 👁️ 4.1K Dilihat ⏱️ 12 menit membaca 🏷️ Rumus Logika, IF Excel, Fungsi Lanjutan

Rumus IF adalah salah satu fungsi paling powerful di Excel yang memungkinkan Anda membuat keputusan logis dalam spreadsheet. Dengan mengombinasikan IF dengan fungsi AND dan OR, Anda dapat membuat kondisi yang kompleks untuk analisis data yang lebih cerdas dan otomatis.

Konsep Dasar: Fungsi IF bekerja dengan prinsip "JIKA kondisi terpenuhi, MAKA lakukan ini, SELAIN ITU lakukan itu".

1. Fungsi IF Dasar

Fungsi IF mengevaluasi suatu kondisi dan mengembalikan satu nilai jika kondisi TRUE, dan nilai lain jika FALSE.

Sintaks Dasar:

=IF(logical_test, value_if_true, value_if_false)

Contoh Sederhana:

Misalkan kita ingin mengecek apakah nilai ujian lulus (>=75) atau tidak:

=IF(B2>=75, "Lulus", "Tidak Lulus")

Jika nilai di sel B2 adalah 80, hasilnya: "Lulus"

Jika nilai di sel B2 adalah 70, hasilnya: "Tidak Lulus"

2. Fungsi AND - Multiple Conditions

Fungsi AND mengembalikan TRUE hanya jika SEMUA kondisi terpenuhi.

Sintaks:

=AND(condition1, condition2, ...)

Contoh dengan AND:

Mengecek apakah seorang siswa lulus ujian DAN memiliki kehadiran minimal 80%:

=IF(AND(B2>=75, C2>=0.8), "Lulus", "Tidak Memenuhi Syarat")

Hanya menghasilkan TRUE jika semua kondisi terpenuhi

3. Fungsi OR - Alternative Conditions

Fungsi OR mengembalikan TRUE jika SALAH SATU kondisi terpenuhi.

Sintaks:

=OR(condition1, condition2, ...)

Contoh dengan OR:

Memberikan diskon jika pelanggan adalah member ATAU total belanja > 1 juta:

=IF(OR(D2="Member", E2>1000000), "Dapat Diskon 10%", "Tidak Dapat Diskon")

4. IF Bersarang (Nested IF)

Anda dapat menyusun beberapa fungsi IF bersama untuk kondisi yang lebih kompleks.

Contoh IF Bersarang untuk Kategori Nilai:

=IF(B2>=90, "A", IF(B2>=80, "B", IF(B2>=70, "C", IF(B2>=60, "D", "E"))))
Nilai Rumus Hasil
95 =IF(B2>=90, "A", ...) A
85 =IF(B2>=90, "A", IF(B2>=80, "B", ...)) B
65 =IF(B2>=90, "A", IF(B2>=80, "B", IF(B2>=70, "C", IF(B2>=60, "D", "E")))) D
Peringatan: Terlalu banyak IF bersarang dapat membuat rumus sulit dibaca dan dipelihara. Pertimbangkan menggunakan fungsi IFS (Excel 2019+) atau VLOOKUP untuk kategori.

5. Kombinasi AND dan OR dalam IF

Anda dapat mengombinasikan AND dan OR untuk membuat kondisi yang lebih kompleks.

Contoh Kasus Kompleks:

Menentukan kelayakan kredit berdasarkan gaji DAN status pekerjaan ATAU memiliki jaminan:

=IF(OR(AND(B2>=5000000, C2="Tetap"), D2="Ya"), "Layak", "Tidak Layak")

Penjelasan: Kredit layak jika (gaji >= 5jt DAN status tetap) ATAU memiliki jaminan

Tabel Referensi Cepat Fungsi Logika

Fungsi Deskripsi Contoh Hasil
IF Percabangan kondisi =IF(A1>10, "Yes", "No") "Yes" jika A1>10
AND Semua kondisi harus TRUE =AND(A1>10, B1<5) TRUE jika A1>10 DAN B1<5
OR Salah satu kondisi TRUE =OR(A1>10, B1<5) TRUE jika A1>10 ATAU B1<5
NOT Membalikkan logika =NOT(A1>10) TRUE jika A1 TIDAK >10
IFS Multiple conditions (Excel 2019+) =IFS(A1>90,"A",A1>80,"B",TRUE,"C") Nilai berdasarkan kondisi

💪 Latihan Praktik

Scenario: Buat sistem penilaian karyawan dengan ketentuan:

  • Performance >= 80 DAN Attendance >= 90% → "Promosi"
  • Performance >= 70 ATAU Attendance >= 85% → "Pertahankan"
  • Selain itu → "Evaluasi"

Rumus yang harus dibuat:

=IF(AND(performance>=80, attendance>=0.9), "Promosi", IF(OR(performance>=70, attendance>=0.85), "Pertahankan", "Evaluasi"))

Tips dan Best Practices

Tip 1: Gunakan referensi sel daripada nilai langsung untuk memudahkan maintenance.
Tip 2: Untuk IF bersarang yang kompleks, pertimbangkan menggunakan helper columns.
Tip 3: Gunakan fungsi IFERROR untuk menangani error dengan elegan.
Peringatan: Pastikan urutan kondisi dalam IF bersarang sudah benar (dari kondisi paling ketat ke paling longgar).

Dengan menguasai rumus IF, AND, dan OR, Anda dapat membuat spreadsheet yang lebih cerdas dan otomatis. Praktikkan dengan berbagai skenario untuk semakin mahir!
