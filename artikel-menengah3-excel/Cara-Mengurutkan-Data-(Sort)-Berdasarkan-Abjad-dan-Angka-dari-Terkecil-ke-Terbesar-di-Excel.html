Cara Mengurutkan Data (Sort) Berdasarkan Abjad dan Angka dari Terkecil ke Terbesar di Excel

📅 15 Juni 2023 👁️ 5.8K Dilihat ⏱️ 10 menit membaca 🏷️ Sort Data Excel, Urutkan Data, Ascending Descending, Tutorial Excel

Mengurutkan data (Sort) adalah salah satu fungsi dasar Excel yang sangat penting untuk analisis data. Dengan fitur ini, Anda bisa mengatur data berdasarkan abjad, angka, tanggal, atau kriteria khusus lainnya. Panduan lengkap ini akan mengajarkan berbagai teknik sorting data di Excel untuk pemula.

1. Apa itu Sort Data di Excel?

Sort Data adalah proses mengatur ulang baris data dalam worksheet berdasarkan nilai dalam satu atau beberapa kolom. Excel menyediakan dua arah pengurutan utama: Ascending (dari terkecil ke terbesar) dan Descending (dari terbesar ke terkecil).

⬆️

Ascending (A-Z)

Urutkan dari terkecil ke terbesar

Contoh: A ke Z, 1 ke 10, 1 Jan ke 31 Des

⬇️

Descending (Z-A)

Urutkan dari terbesar ke terkecil

Contoh: Z ke A, 10 ke 1, 31 Des ke 1 Jan

🔢

Multi-Level Sort

Urutkan berdasarkan beberapa kolom

Contoh: Departemen lalu Nama

🎯

Custom Sort

Urutan berdasarkan kriteria khusus

Contoh: Low, Medium, High

📌 Penting Sebelum Sorting:
  • Pastikan seluruh data terpilih atau Excel akan mengurutkan sebagian data saja
  • Data dengan header harus ditandai agar header tidak ikut diurutkan
  • Backup data penting sebelum melakukan sorting kompleks
  • Perhatikan merged cells karena bisa menyebabkan error saat sorting

2. Mengurutkan Data Abjad (A-Z)

Sorting data teks atau abjad adalah yang paling umum digunakan. Excel akan mengurutkan berdasarkan urutan alfabet.

Langkah-langkah Sort Abjad A-Z

1

Pilih Data

Pilih range data yang ingin diurutkan

Tips: Klik salah satu sel dalam kolom yang ingin diurutkan

2

Buka Menu Sort

Pergi ke Data tab → Sort & Filter

Klik tombol Sort A to Z (A-Z)

3

Konfirmasi Header

Jika data memiliki header, pastikan pilihan "My data has headers" dicentang

Ini mencegah header ikut terurut sebagai data

4

Selesai

Data akan langsung terurut berdasarkan abjad

Untuk urutan terbalik, gunakan Sort Z to A (Z-A)

4. Mengurutkan Data Tanggal

Excel secara otomatis mengenali format tanggal dan bisa mengurutkannya dari terlama ke terbaru atau sebaliknya.

Format Tanggal Sort Ascending Sort Descending Keterangan 01/06/2023 01/06/2023, 02/06/2023, ... 31/12/2023, 30/12/2023, ... Format tanggal standar 1 Juni 2023 1 Juni, 2 Juni, 3 Juni... 31 Des, 30 Des, 29 Des... Format tanggal panjang Jun-23 Jan-23, Feb-23, Mar-23... Dec-23, Nov-23, Oct-23... Format bulan-tahun Senin, Selasa Senin, Selasa, Rabu... Minggu, Sabtu, Jumat... Nama hari

Cara Sort Data Tanggal

1

Pastikan Format Tanggal

Pastikan data dikenali Excel sebagai tanggal

Cek dengan mengubah format sel ke Date

2

Pilih Kolom Tanggal

Klik salah satu sel dalam kolom tanggal

Atau pilih seluruh range data

3

Sort Oldest to Newest

Data → Sort & Filter → Sort Oldest to Newest

Untuk urutan dari tanggal terlama

4

Sort Newest to Oldest

Data → Sort & Filter → Sort Newest to Oldest

Untuk urutan dari tanggal terbaru

5. Sort Multi-Level (Berdasarkan Beberapa Kolom)

Sort multi-level memungkinkan pengurutan data berdasarkan beberapa kriteria secara berurutan.

🔢 Contoh Sort Multi-Level

Departemen → Nama

Urutkan berdasarkan departemen, lalu nama

Status → Tanggal

Urutkan berdasarkan status, lalu tanggal

Kota → Gaji

Urutkan berdasarkan kota, lalu gaji

Contoh: Urutkan berdasarkan Departemen (A-Z), lalu Nama (A-Z)

Sebelum Sort:

HR - Budi
IT - Ani
HR - Cici
IT - Dedi

Setelah Sort:

HR - Budi
HR - Cici
IT - Ani
IT - Dedi

Level Kolom Urutan Hasil
Level 1 Departemen A to Z HR, IT, Marketing
Level 2 Nama Karyawan A to Z Ani, Budi, Cici dalam tiap departemen
Level 3 Tanggal Masuk Oldest to Newest Karyawan lama ke baru dalam tiap departemen & nama

Langkah Sort Multi-Level

1

Buka Dialog Sort

Data → Sort & Filter → Sort

Atau gunakan shortcut Alt + D + S

2

Tambah Level Pertama

Pilih Column untuk level pertama

Atur Sort On dan Order

3

Tambah Level Berikutnya

Klik Add Level

Atur kolom dan urutan untuk level kedua

4

Terapkan Sorting

Tambahkan level sesuai kebutuhan

Klik OK untuk menerapkan

7. Tips dan Trik Ahli

💡 Tips Sort Data Level Ahli:
  • Expand selection saat sorting untuk menjaga hubungan antar kolom
  • Gunakan Sort Left to Right untuk mengurutkan baris, bukan kolom
  • Backup data sebelum melakukan sorting kompleks
  • Gunakan Table Format untuk sorting yang lebih mudah dan aman

⚠️ Masalah Sorting yang Sering Terjadi:

  • Data terpisah - Pastikan pilih seluruh range data
  • Header ikut terurut - Centang "My data has headers"
  • Tanggal tidak urut - Pastikan format sel adalah Date
  • Merged cells error - Hindari merged cells dalam data yang diurutkan

Kesimpulan

Menguasai Sort Data di Excel adalah keterampilan fundamental yang akan meningkatkan efisiensi analisis data Anda. Dengan teknik-teknik yang telah dipelajari, Anda bisa:

  • Mengurutkan data teks secara alfabetis (A-Z atau Z-A)
  • Mengurutkan data angka dari terkecil ke terbesar atau sebaliknya
  • Mengatur data tanggal dari terlama ke terbaru
  • Melakukan sort multi-level berdasarkan beberapa kriteria
  • Membuat custom sort dengan urutan khusus

Practice makes perfect! Coba buat worksheet latihan dan praktikkan semua teknik sorting yang telah dipelajari. Mulai dari sorting sederhana hingga multi-level dan custom sort.
