💡 Cara Kerja CSS Class Toggles

1
JavaScript hanya menangani class
Menambah/hapus class CSS berdasarkan event drag & drop
2
CSS menangani semua feedback visual
Transisi, animasi, dan perubahan style diatur oleh CSS
3
State yang berbeda dengan class berbeda
.dragging, .drag-over, .success-drop, dll
4
Validasi drop dengan class
.will-accept untuk target valid, .invalid-target untuk tidak valid
